# Security policy

## Reporting a problem

Please do **not** open a public issue for a security problem.
Use GitHub "Private vulnerability reporting" on this repository.
Describe the problem, the steps to repeat it, and the version.
We will answer as soon as we can.

## Supported versions

Only the latest release gets security fixes while the project is in 0.x.

## Important warning

The first admin user is created with a default password that is public in the source code.
Change it before you go to production. See `docs/seeding.md`.
